## Overview

A chatbot that answers questions from King James Version Bible text using a retrieval-augmented generation pipeline.

## What I built

- A **RAG pipeline** using **ChromaDB** and Python for high-accuracy queries over structured data.
- **spaCy** preprocessing of the source text.
- **Query expansion** and **semantic search** to improve retrieval accuracy for varied user phrasing.
- Deployment to **HuggingFace** for model hosting.

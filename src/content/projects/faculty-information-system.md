## Overview

An information system for a government-affiliated project, used by 50+ faculty members. It compacts administrative workflows into one place.

## What I built

- The frontend in **Laravel/Blade**.
- A responsive, "Blackboard-style" navigation designed to improve usability.
- Secure user registration.
- **Client-side validation** to keep data consistent between the frontend and the **MySQL** database.
